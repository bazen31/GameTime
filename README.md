# GameTime

Приложение для бронирования компьютеров и консолей игрового клуба. Реализовано на Flask, SQLite и серверных шаблонах Jinja; интерфейс адаптируется для телефонов.

## Запуск на Windows

Требуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
flask --app gametime:create_app init-db
flask --app gametime:create_app seed
flask --app gametime:create_app run --debug
```

Откройте `http://127.0.0.1:5000`. База SQLite создаётся в `instance\gametime.sqlite3`; схема и индексы описаны в `schema.sql`.

Для стабильных сессий задайте собственный секрет сессии перед запуском. Если переменная не задана, приложение создаст случайный секрет при старте:

```powershell
$env:SECRET_KEY = "длинная-случайная-строка"
```

`init-db` безопасно создаёт отсутствующие таблицы и начальные настройки; `seed` добавляет демонстрационные данные только в пустую базу. Для чистого повторного запуска удалите только `instance\gametime.sqlite3` и снова выполните команды инициализации.

## Реализовано

- Каталог PC/консолей с фильтрами по типу и зоне, расписанием занятости и страницей устройства.
- Регистрация, вход, выход, профиль, клиентские и административные роли. Служебная роль задаётся только администратором; доступ проверяется на сервере.
- Бронирование с шагом 30 минут, расчётом тарифа и суммы на сервере и неизменяемым снимком цены.
- Атомарная проверка пересечений в SQLite-транзакции `BEGIN IMMEDIATE`; пересекающиеся активные брони запрещены, соседние интервалы разрешены.
- Отмена своей будущей подтверждённой брони, начало/завершение сеанса и отметка неявки администратором.
- Настройки адреса, рабочего интервала и часового пояса; отчёт занятости и суммы завершённых сеансов.
- Демоданные: 8 устройств, 2 зоны, 3 клиента и 15 броней различных статусов.

Внешняя оплата и управление ОС игровых компьютеров не реализованы.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют пересечения и соседние интервалы, одновременные запросы, фиксацию стоимости, освобождение интервала после отмены и серверные проверки ролей.
